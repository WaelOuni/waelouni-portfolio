## Remaining findings and reachability

- **Astro 5.18.2 (critical aggregate; npm target 7.4.2):** multiple XSS/SSRF/auth advisories plus AVIF image-optimization RCE. The RCE requires an attacker to cause Astro/Sharp to optimize a malicious AVIF; this project uses trusted local assets, has no runtime image endpoint, and serves static files. Untrusted build contributions remain in scope. Astro’s advisory specifies the precondition and fix Astro 7.2.8 / Sharp 0.35.4.
- **Sharp 0.34.5 (high):** inherited native image library vulnerabilities; Astro 5 pins the older Sharp line. No untrusted uploads or runtime image processing exist here. Patched releases are in the 0.35 line.
- **esbuild 0.27.7 (low):** advisory is limited to its Windows development server; it is build/dev-only and production is static. Fix 0.28.1 is outside Astro 5’s dependency range.
- **Tailwind CSS 3 tree (high/moderate):** braces 3.0.3 has no patched release published; chokidar/fast-glob/micromatch inherit that path. Tailwind 4.3.3 is the available clean tree but is a major migration. postcss-selector-parser 7.1.6 is also required and crosses the current Tailwind 3 dependency range. These parsers process repository-controlled CSS during builds, not public request data.

**Why not apply the remaining fixes now:** npm proposes major Astro/Tailwind lines that alter core build integration. Applying them inside this hardening pass would combine an unreviewed framework migration with the completed UX release. No exclusions or overrides were added. The remaining packages are included in the install tree and CI/Docker build; they are not in the static production runtime, but the critical Astro alert still requires a reviewed major upgrade before treating the dependency audit as clean.

**Release decision:** the compatible lockfile update reduced affected packages by 16. Audit remains nonzero, including a critical Astro aggregate. Treat as **NOT READY FOR PRODUCTION** until Astro 7 / Tailwind 4 or upstream-compatible patches are reviewed and the audit rerun.
